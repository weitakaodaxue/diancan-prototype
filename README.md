# 点餐 App · 低保真交互原型

一个用 **Axure RP 9** 制作的外卖点餐 App 低保真交互原型，覆盖课程要求的 10 个交互知识点。

> 低保真（Low-Fidelity）原型关注的是**信息结构与交互流程**，不使用真实图片与配色，所有图片位置均为矢量占位框。

---

## 页面结构

| 页面 | 作用 |
|---|---|
| **登录** | 账号密码输入、验证码、协议勾选、登录成功 / 密码错误提示 |
| **首页** | 顶部图片轮播、搜索框、菜品推荐、底部导航栏 |
| **订单** | 进行中 / 历史订单 / 线下订单 三个分类 |
| **订单详情** | 订单状态、菜品明细 |
| **我的二维码** | 取餐码 |

---

## 十个交互知识点

| # | 知识点 | 实现方式 |
|---|---|---|
| 1 | **图片轮播** | 首页顶部动态面板，多状态 + 自动循环切换（等待 → 设置面板状态） |
| 2 | **热区** | 轮播区域、搜索框各放置 1 个热区（`ImageMapRegion`） |
| 3 | **文本框、下拉框** | 文本框 ×2、下拉列表框 ×2 |
| 4 | **单选按钮、复选按钮** | 单选按钮 ×2、复选按钮 ×4，勾选状态互相联动 |
| 5 | **动态面板** | 全项目共 12 个动态面板，负责轮播、弹层、状态切换 |
| 6 | **中继器** | 菜品列表使用中继器 + 数据表，通过 `[[Item.Column0]]` 绑定数据 |
| 7 | **内联框架** | 内联框架 ×2 |
| 8 | **动作交互、情形交互** | 6 类动作共 17 个：打开链接、设置面板状态、淡入淡出、等待、移动、设置函数；交互情形 6 个，含条件判断 |
| 9 | **变量（全局 / 局部）** | 全局变量 `vYhm`（用户名）、`mm`（密码）；局部变量 `LVAR` ×6 |
| 10 | **函数、表达式** | 字符串拼接、`.length` 求长度、`Now.getHours()` 取时间、`LVAR1.left+12` 坐标运算 |

### 用到的表达式

```
[[ "欢迎回来，" + vYhm ]]
[[ "已输入 " + yhm.text.length + " 个字符" ]]
[[ "现在 " + Now.getHours() + " 点" ]]
[[vYhm]]
[[mm]]
[[This.scrollY]]
[[LVAR1.left+12]]
[[LVAR1.bottom-2]]
[[Item.Column0]]
```

## 如何打开

1. 安装 **Axure RP 9**（Windows / macOS）
2. 下载本仓库中的 `点餐低保真.rp`
3. 双击打开，按 `F5` 预览原型
