# 外卖点餐 · 低保真原型

一个外卖点餐 App 的**低保真交互原型**，提供两种形态：

- 🌐 **HTML 版**：双击即开，任何人用浏览器就能操作，无需安装任何软件
- 📦 **Axure 版**：`.rp` 源文件，用于继续编辑与课程提交

---

## 🌐 在线体验

**https://weitakaodaxue.github.io/diancan-prototype/**

手机上也可以直接打开（375×812 移动端画布）。

---

## 页面结构

### HTML 版（3 屏，可交互）

| 屏幕 | 内容 |
|---|---|
| **首页** | 定位地址、搜索框、图片轮播（自动 + 左右箭头 + 指示点）、热区、分类导航、排序下拉、店铺列表、底部导航栏 |
| **店铺页** | 店铺信息、菜单分类切换、菜品规格弹层（规格选项 + 加料 + 数量增减 + 价格实时计算）、加入购物车、购物车抽屉（增删、清空、合计） |
| **结算页** | 收货人表单与校验、内联框架地图、餐具份数、优惠/配送/应付金额计算、下单成功提示 |

### Axure 版（5 页）

| 页面 | 内容 |
|---|---|
| 登录 | 账号密码、验证码、协议勾选、成功 / 错误提示 |
| 首页 | 轮播、搜索、菜品推荐、底部导航 |
| 订单 | 进行中 / 历史订单 / 线下订单 |
| 订单详情 | 订单状态与明细 |
| 我的二维码 | 取餐码 |

## 十个交互知识点

| # | 知识点 | 实现 |
|---|---|---|
| 1 | **图片轮播** | 首页顶部多状态切换 + 自动循环 + 左右手动切换 + 指示点 |
| 2 | **热区** | 轮播区域、搜索框热区 |
| 3 | **文本框、下拉框** | 搜索框、表单输入框；排序 / 分类下拉选择 |
| 4 | **单选按钮、复选按钮** | 规格单选、加料多选，状态联动并影响价格 |
| 5 | **动态面板** | 多屏切换、规格弹层、购物车抽屉、遮罩层 |
| 6 | **中继器** | 菜品 / 店铺列表数据驱动渲染 |
| 7 | **内联框架** | 结算页地图、用户协议页 |
| 8 | **动作交互、情形交互** | 6 类动作共 17 个，含条件判断与多情形分支 |
| 9 | **变量（全局 / 局部）** | 全局变量 `vYhm`（用户名）、`mm`（密码）；局部变量 `LVAR` ×6 |
| 10 | **函数、表达式** | 字符串拼接、`.length`、`Now.getHours()`、坐标运算 |

### Axure 中用到的表达式

```
[[ "欢迎回来，" + vYhm ]]
[[ "已输入 " + yhm.text.length + " 个字符" ]]
[[ "现在 " + Now.getHours() + " 点" ]]
[[vYhm]]
[[mm]]
[[This.scrollY]]
```

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | HTML 低保真原型，单文件、零依赖、离线可用（约 54 KB） |
| `点餐低保真.rp` | Axure RP 9 项目源文件（约 604 KB） |

- 无外部图片、无 CDN、无网络请求，全部为矢量图形与占位框
- 符合低保真原型「重结构、轻视觉」的要求

## 如何打开

**HTML 版**：双击 `index.html`，或直接访问上面的在线链接。

**Axure 版**：

1. 安装 Axure RP 9（Windows / macOS）
2. 下载 `点餐低保真.rp`
3. 双击打开，按 `F5` 预览
